# Documentation détaillée

Les documents de référence sont à la racine de `ai-scene-studio/` (README, ARCHITECTURE, SCENE_SCHEMA,
API, DEVELOPMENT, DEPLOYMENT, SECURITY, TESTING, KNOWN_LIMITATIONS, CHANGELOG). Ce dossier accueillera
les compléments détaillés au fil des phases :

- `architecture/` : décisions d'architecture détaillées (ADR) ;
- `api/` : exemples de requêtes et schémas générés ;
- `development/` : guides pas à pas ;
- `deployment/` : procédures d'exploitation.
