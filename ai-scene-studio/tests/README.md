# Tests transverses

- `fixtures/` : données partagées entre langages (scènes canoniques de référence).
- `integration/` : scénarios multi-services (création projet → révision → job), à partir de la phase 1.
- `e2e/` : parcours utilisateur complets (critères d'acceptation du MVP), à partir de la phase 1.

Les tests propres à un package restent dans ce package. Voir [TESTING.md](../TESTING.md).
