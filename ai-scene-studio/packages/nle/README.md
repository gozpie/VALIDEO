# Moteur de montage (`@valideo/*`)

Moteur de montage image par image repris du NLE web VALIDEO (branche
`claude/video-editing-software-analysis-om0bn7`, dossier `nle/packages`). Temps rationnel, modèle
de timeline, commandes annulables, moteur de timeline, démultiplexage MP4, audio, lecture.

Ces packages sont publiés en TypeScript source (comme les `@ass/*`) et utilisés par l'écran Montage
de `apps/web/src/montage`.
